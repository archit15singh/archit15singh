# Archit Singh

## Email security, AI agents and detection at scale.

I am a **Senior Software Engineer at [Abnormal AI](https://abnormal.ai/)**, building AI agents and detection systems for email security. My work connects detection engineering with reliable backend and agent systems. I presented **Memory is the Agent: Architecting Stateful Reasoning** at PyCon India 2025.

Abnormal's platform operates at billion-message scale. Its [public architecture article on AWS](https://aws.amazon.com/blogs/machine-learning/abnormal-ai-amazon-bedrock-agentcore-for-agentic-email-security-at-scale/) explains the layered detection approach and selective use of agents.

### Independent projects

- **[Lorevell](https://github.com/archit15singh/lorevell)** (formerly Memori): local knowledge for humans and agents. Markdown files are the source of truth; SQLite is a rebuildable search index. Existing coding agents supply the reasoning. See the repository for current source installation instructions and the [rename guide](https://github.com/archit15singh/lorevell/blob/main/docs/rebrand.md).
- **[Luffy](https://github.com/archit15singh/luffy-pr-review-agent)**: a comment-triggered PR review agent with repository-specific memory and redacted execution traces.
- **[SpliceForge](https://github.com/archit15singh/spliceforge)**: an AI-assisted video-editing tool built around Codex. The [evaluation harness](https://github.com/archit15singh/video-editing-agent-bench) tracks the work needed to test it.

### Writing and speaking

I write about email security, detection engineering and reliable AI agents, including how agents preserve useful context, act within constraints, recover from failures and expose enough evidence to check what they did. My writing connects implementation choices with experiments and their limits.
